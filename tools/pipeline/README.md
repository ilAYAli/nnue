# pipeline

`pipeline` is the orchestration layer for full experiments.

It executes the configured phase list generated by `build.py`. It is generic:
it does not know NNUE semantics, only steps, logs, done markers, events, hooks,
and status.

## Commands

```sh
tools/pipeline/pipeline.py status RUN_DIR
tools/pipeline/pipeline.py launch config.json
```

`launch` accepts JSON or YAML if PyYAML is installed.
It appends generic JSON events to `events.jsonl`. If an event hook is configured,
the same event JSON is passed to the hook on stdin and in `NNUE_RUN_EVENT_JSON`.

Example:

```json
{
  "run": "~/code/cpp/chess/nnue/runs/example",
  "steps": [
    {
      "name": "pack",
      "command": [
        "tools/pack/pack.py",
        "build",
        "--input",
        "{score}/labeled.jsonl",
        "--out-dir",
        "{pack}/train"
      ]
    }
  ]
}
```

Optional event hook:

```json
{
  "run": "~/code/cpp/chess/nnue/runs/example",
  "hooks": {
    "event_command": "~/code/cpp/chess/nnue/tools/events/nnue_event_ntfy.sh"
  },
  "steps": []
}
```

or:

```sh
tools/pipeline/pipeline.py launch config.json --on-event "$HOME/code/cpp/chess/nnue/tools/events/nnue_event_ntfy.sh"
```

If `run` is omitted, the default is:

```text
~/code/cpp/chess/nnue/runs/<timestamp>/
```

Run directories use this layout:

```text
config.yml
manifest.json
status.json
logs/
assets/
posgen/
score/
pack/
train/
validate/
```

The tracked NNUE ntfy hook publishes normal build events to `/nnue` and
self-notification prompts to `/AI_stdin` for `phase_done`, `done`, and `fail`.
